# 個人筆記整理網站

使用 HTML、CSS、JavaScript 的靜態課程筆記網站。第一版包含使用者提供的 ３ 門課程、４ 篇筆記及原始公關筆記的 ８ 張圖片。

## 本機預覽

在專案目錄開啟終端機，執行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

使用瀏覽器開啟 `http://127.0.0.1:4173`。由於網站透過 `fetch` 讀取 Markdown，請使用 HTTP 預覽，不要直接以 `file://` 開啟 HTML。

## 使用方式

- 進入網站根網址時顯示首頁，可查看依 `notes/index.json` 動態計算的課程與筆記總數。
- 從左側側邊欄選擇課程與筆記進入閱讀模式；課程可展開或收合。
- 點選網站名稱或上方「我的筆記」可返回首頁。
- 搜尋會比對所有筆記標題與文字內文；按 `/` 可移至搜尋欄。
- 文章目錄依 H2、H3 產生，可點選跳轉，網址也可直接連至筆記或章節。
- 手機使用上方選單開啟課程列表；文章目錄預設收合。

## 內容與檔案

- `notes/index.json` 僅記錄標題、課程及載入所需的檔案位置與識別碼。
- `notes/*.md` 為附件轉換的筆記內容；`assets/` 保留附件圖片。
- 原文中的補圖與繪圖提示標示為 `[待補充]`，未新增外部知識，也未校正原文的事實敘述。
- `js/vendor/` 隨附 Marked 及其授權，執行時不依賴遠端 JavaScript。
- Noto Sans TC 透過 Google Fonts 載入；離線時使用本機無襯線備援字體。
- `tools/import-notes.py` 為此次附件轉換工具，讀取指定的原始文件及 `.work/` 中舊版 Word 的轉換副本。平常瀏覽與部署不需要執行。

## GitHub Pages

將網站檔案推送至 GitHub，於儲存庫設定中啟用 Pages，以存放 `index.html` 的分支根目錄作為來源即可，無須建置或後端。網站資源使用相對路徑，支援儲存庫子路徑。請勿將 `.work/` 的文件副本一起發布。
