# 個人筆記整理網站

> 把學過的，慢慢整理成自己的。

以課程為單位整理 Markdown 筆記的個人知識庫，提供搜尋、閱讀與複習所需的簡單介面。採用奶油米色與淺色閱讀區，支援桌面與手機瀏覽，使用原生 HTML、CSS、JavaScript 開發，可部署至 GitHub Pages。

## 功能特色

- **首頁總覽**：以兩張統計卡片顯示動態計算的課程與筆記總數。
- **課程導覽**：從可展開、收合的側邊欄選擇筆記，同一課程依筆記標題排序。
- **關鍵字搜尋**：搜尋筆記標題與文字內文，快速找到需要複習的內容。
- **Markdown 閱讀**：支援清單、表格、程式碼與圖片。
- **文章目錄**：依 H2、H3 產生目錄，支援章節跳轉、目前閱讀章節標示與獨立捲動。
- **響應式介面**：桌面呈現課程、筆記與目錄；手機提供可收合的側邊欄與文章目錄。
- **筆記與章節連結**：可透過網址直接開啟指定筆記或章節。

目前以閱讀與整理既有筆記為主，網站介面不提供新增或編輯功能。

## 使用方式

1. 開啟網站首頁，查看課程與筆記統計。
2. 從左側側邊欄選擇課程與筆記，進入閱讀模式；手機可先開啟上方選單。
3. 使用搜尋欄尋找標題或內文關鍵字，也可按 `/` 移至搜尋欄。
4. 點選文章目錄跳至對應章節。手機版目錄預設收合，可按「本篇目錄」展開。
5. 點選網站名稱或上方「我的筆記」返回首頁。

## 技術與設計

| 項目 | 說明 |
| --- | --- |
| 前端 | 原生 HTML、CSS、JavaScript，無前端框架 |
| 筆記資料 | Markdown 內容與 JSON 索引 |
| 視覺 | 奶油米色、鼠尾草綠強調色，僅提供淺色模式 |
| 字體 | Noto Sans TC 與等寬程式碼字體；字型無法載入時使用備援字體 |
| 部署 | 靜態檔案，無須後端、資料庫或建置步驟 |

## 專案結構

```text
.
├── index.html             網站入口
├── css/style.css          網站樣式與響應式配置
├── js/
│   ├── main.js            首頁、搜尋、導覽與閱讀互動
│   └── vendor/            Markdown 解析器與授權文件
├── notes/
│   ├── index.json         實際筆記清單與課程對應
│   └── *.md               筆記內容
├── assets/                圖片與靜態資源
├── tools/import-notes.py  指定 Word 文件的轉換工具
├── AGENTS.md              內容整理與維護規範
└── README.md              專案介紹與使用說明
```

## GitHub Pages 部署

將網站檔案推送至 GitHub 儲存庫，於儲存庫設定中啟用 Pages，以存放 `index.html` 的分支根目錄作為來源即可，無須建置或後端。

網站使用相對路徑，支援儲存庫子路徑部署。部署時保留 `.nojekyll`，並排除 `.work/` 中的本機轉換副本與檢查暫存。

## 筆記整理原則

筆記僅依提供的原始文字、程式碼與脈絡整理，可調整排版與章節結構，不自行補入外部知識或改變原意。資訊缺漏或尚未提供的圖片以 `[待補充]` 保留，完整規範見 [AGENTS.md](AGENTS.md)。
